## Keterangan Data

| Field            | Keterangan                                                         |
| ---------------- | ------------------------------------------------------------------ |
| Nama Karyawan    | Nama lengkap pengguna laptop                                       |
| Jabatan / Divisi | Posisi dan departemen pengguna                                     |
| Email Outlook    | Email resmi perusahaan (@kencanaglobal.com)                        |
| Email Gmail      | Email pribadi atau email pendukung                                 |
| Username Laptop  | Username login Windows                                             |
| Password Laptop  | Password yang dibuat melalui server lokal kantor                   |
| Model Laptop     | Contoh: Dell Latitude 5420, Lenovo ThinkPad E14, HP ProBook 440 G9 |
| Serial Number    | Nomor seri perangkat                                               |
| Asset Tag        | Nomor inventaris perusahaan                                        |
| Status           | Aktif, Cuti, Resign, Rusak, Cadangan                               |
| Catatan          | Informasi tambahan terkait perangkat                               |
